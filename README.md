# Olivier Dreyer — Professional Site

Static professional site for Olivier Dreyer.

The site includes Compass, an independent Strategy & Operations case study
exploring accountable use of AI in operational workflows.

## Structure

- `/` — professional landing page
- `/compass/` — Compass case study

## Development

The site uses plain HTML and CSS with no application framework or external
runtime dependencies. There is no build step.

To preview locally:

```powershell
Set-Location "C:\Dev\Olivier-Dreyer-Site"
.\serve.ps1
```

Then open <http://localhost:8000/>.

Public examples use synthetic data.
